# pedidos-legado

Serviço de pedidos sem doc-set. Fixture do claude-code-kit: é o que os comandos
encontram no mundo real — sem `CLAUDE.md`, com convenções misturadas e dívida
que ninguém registrou. Existe para as suítes provarem que o kit funciona **sem**
contrato, e que a família `C` não inventa fronteira quando não há nenhuma
declarada.
